   (see `.env.local.example`; the project ID is in the Sanity dashboard). It is
   not in git.
3. Run the dev server on **port 5173 only**: `npm run dev -- --port 5173 --strictPort`.
   Sanity's CORS allows only `http://localhost:5173`, so any other port shows an
   empty site. The Playwright config also points at 5173, so tests test
   whatever is running there. Make sure it is your own current code.
4. Playwright now runs with reduced motion (see `playwright.config.js`), so the
   loader and arrival animations are skipped in tests.

## What Quin wants (this is the important part)
Quin has said several times that the site is not interesting or entertaining
enough yet. Phases 1 to 4 were a colour change plus quiet static marks, and the
two motion scenes built so far are small. The target is the feel of three
reference portfolios Quin showed (a social media manager, a UGC video editor, a
video editor): **the page is built from the tools of the person's craft, and
scrolling drives a story**. A feed that fills, an editor that assembles, an
export bar with filenames, a counter dropping from 3:12:00 to 0:58. Not copying
their look, only the principle. Quin approved raising the ambition: scroll-driven
scenes, even if they add some scroll, one at a time, each shown to Quin first.

## Gotchas learned
- The editing tool refuses edits in the shared checkout during a background
  session. Work in a worktree (`.claude/worktrees/...`). A new worktree starts
  from `main`, so check it has the files you expect.
- `git` through the Bash tool sometimes crashes on this machine. PowerShell
  works. A PowerShell "NativeCommandError" on `git push` is just git's progress
  text.
- A screenshot taken during the Product sweep can trigger a resize that ends it,
  which is correct behaviour. To check it, poll the page's `.inspect-readout`
  instead.
- Frame numbers use a dark chip so they read on bright images.
- The first load of the dev server is slow (about 7 seconds of blank white while
  Vite compiles). It is a dev-server effect, not the loader.
- Editing a file that holds a React context (for example
  `ProjectsContext.jsx`) while the page is open makes Vite's hot reload drop the
  context, and the page goes blank with "Cannot destructure ... as it is null".
  A full reload fixes it. It is not a real bug.
- A shell `sed -i` on a CRLF file can rewrite every line ending, so the plain
  diff looks like the whole file changed. `git diff --ignore-space-at-eol` shows
  the real change. Git normalises line endings on commit.
- The browser screenshot tool's coordinates are scaled differently from the
  page's CSS pixels (for example 1568 wide against a 1920px window). Hover by
  the screenshot's own coordinates, or read element rectangles and scale them.
- Theme state: `sessionStorage` `hub-scanned` controls the loader, and
  `localStorage` `hub-theme` is the shared theme (`night` or `light`).
- On this PC only: `ffmpeg` was installed with winget, and the reference-video
  frames are in `D:\Users\Quin\Downloads\video-frames`. Neither is in the repo.
