# Fujifilm Nationwide Photo Walk 2026: photo set paste sheet

Field-by-field guide for creating this photo set in Studio. Same format as the
case study paste sheets in this folder. It follows Studio **top to bottom**.
Each `##` heading is a Studio tab, and each `###` heading is a box inside that
tab.

**How to use this sheet:**

- **Bold value / `code`** → type or paste it in.
- *leave empty* → don't fill it in.
- *Placeholder in [square brackets]* → fill in once you've uploaded the photo.

**Preview while you work:** run `npm run dev`, then open
`http://localhost:5173/visual/<slug>` (the slug Studio creates from the title).
An old `/work/<slug>` link redirects there.

## Tab: Photos

The Story, Outcome and Legacy tabs are hidden for photo sets, so there's
nothing to fill in there.

### Box: Photos (the list)

**Order:** highlighted photos appear first on the page, automatically. The
rest follow in the order you list them here. Put your strongest unhighlighted
photo first.

#### Photo 1: highlight (the Top 20 entry)

| Studio field | Enter |
|---|---|
| Photo | **[Upload the full-size highlight file]** |
| Alt text | **[Written once you share the photo]** |
| Caption (optional) | *leave empty* |
| Highlight this photo | **On** |
| Recognition (optional) | **Top 20 Finalist, Mindanao · Open Photo Category · Fujifilm Nationwide Photo and Video Walk 2026** |

#### Photo 2 onward: the rest of the set

Copy this block for each photo you upload.

| Studio field | Enter |
|---|---|
| Photo | **[Upload the file]** |
| Alt text | **[Written once you share the photo]** |
| Caption (optional) | *leave empty* (or your own line) |
| Highlight this photo | *leave as is* (Off) |
| Recognition | *hidden when Highlight is off; leave empty* |

> Studio warns if you have more than three highlights. This set has one.

## Before you publish

- Check the **Fujifilm Nationwide** spelling in the recognition line.
- Confirm the intro and short description are in your own words. Edit anything
  that doesn't sound like you.
- Set **Status** to Published only when all photos and alt text are in.
