What I Worked From

Four sources, no formal research

I didn't run interviews or usability tests on this project. My decisions came from what was already in front of me.

The Excel templates

The AOP and PPMP sheets staff were using, which showed everything each plan had to capture.

The inherited design

The previous designer's screens and the half-built system based on them.

The developers

Conversations with the two frontend developers and one backend developer about where the build kept breaking.

Staff feedback

Complaints already coming in about the form, and later, feedback on how resources were displayed.

I didn't get to test with planning staff during the project, so the design hasn't been validated in use.

The Design I Inherited

The replacement had the same shape as the spreadsheet

When I joined, the system had been in development for six months without a stable build. The first design put the whole plan into a single form. It already saved drafts, so losing work wasn't the issue. Getting to the fields was.

Why it stalled
Because the form was linear, one missing piece of data held up the entire submission. That much interlinked data in one place was also what the developers couldn't stabilize.
Constraints1 designer, 3 developersDesign alongside developmentStaff aged 20–60Mixed comfort with software

The Challenge

Restructure the plan so staff could fill it in, and developers could build it, one part at a time, without losing the link between what a unit plans and what it buys.

The Process

Design ran alongside development, so each step went to the developers as soon as it was ready.

01

Diagnose the stalled build

Reviewed the inherited design, talked with the developers, and read the complaints already coming in.

02

Restructure the plan

Split the single form into the plan's own levels, each saving on its own.

03

Design each level

An item library for resources. Kept the card view and added a table view.

04

Lock and submit together

Worked out the AOP lock with the developers, then the combined submission and approval timeline.

Feedback loop at step 03: staff asked for a list like their Excel sheets, so I added the table view.
